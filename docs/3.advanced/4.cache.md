---
title: Cache
description: In-memory cache of permissions and roles.
navigation:
  icon: i-tabler-database
---

Permissions are cached in memory to avoid repeated queries.

```ts [config/permissions.ts]
defineConfig({
  // ...
  cache: { enabled: true, key: 'adonisjs_permission_cache', ttl: '24h' },
})
```

The cache is invalidated automatically when you use the package methods (`assignRole`, `givePermissionTo`, ...). If you change data directly in the database or from another process, clear it:

```bash
node ace permissions:cache-reset
```

or in code:

```ts
import { PermissionRegistrar } from '@eienjs/adonisjs-permission'

PermissionRegistrar.getInstance().forgetCachedPermissions()
```
